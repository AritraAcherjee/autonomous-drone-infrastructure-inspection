# P19 evaluation asset provenance

`honeycombing_v1.png` is generated solely by
`generate_honeycombing_texture.py`, version `P19-HONEYCOMB-PROCEDURAL-v1`,
with seed `1903001`. The generator uses only arithmetic and Python standard
library PNG encoding. It consumes no dataset, photograph, model output, or
external image.

The project authors own this evaluation-only synthetic asset. It is not a
training asset and does not assert that the appearance is representative of
physical honeycombing. It must not be changed after any detector output is
observed for this experiment.
