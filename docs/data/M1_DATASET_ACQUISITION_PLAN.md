2026-09-11 — No additional dataset download is required before Chat 03. Planned for the project does not mean required for M1. The first detector uses the already approved GYU-DET baseline alone. GYU true values describe a prerequisite already satisfied, not unfinished acquisition. All other datasets have A/B/C=false. DEFER means valuable planned work, not proof every optional experimental component is mandatory. Gazebo alone is explicitly REQUIRED_LATER for integrated system verification.

At each owning-workstream entry: clear unresolved permissions, choose the minimal useful subset, record version/source/checksums and terms, then validate sensors, annotations and leakage. Do not download all Hilti releases by default. HOLD is a current prohibition on acquisition/use; optional future usefulness does not override it.
